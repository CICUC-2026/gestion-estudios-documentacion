# ADR-004 — Identidad visual propia con navegación superior

**Estado:** aceptada  
**Fecha:** 2026-07-17

## Decisión

La aplicación usará una barra horizontal superior como navegación principal y un sistema visual propio de CICUC. No copiará el diseño de otro producto.

## Consecuencias

- la arquitectura del layout priorizará contenido ancho y tablas;
- la navegación móvil será una adaptación responsiva, no una app móvil;
- paleta, tipografía y marca definitivas quedan pendientes de insumos de CICUC;
- prototipos iniciales usarán tokens neutrales y accesibles.
