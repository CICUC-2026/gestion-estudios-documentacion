# Feature — Fundamentos de la plataforma

**Estado:** en-desarrollo  
**Última actualización:** 2026-08-04

## Objetivo

Entregar una base ejecutable y segura sobre la cual desarrollar los dominios clínico-operativos sin IA ni decisiones automáticas.

## Incluye

- repositorios, convenciones y CI;
- entornos locales reproducibles;
- usuarios, autenticación, roles y permisos;
- auditoría básica;
- layout web con navegación horizontal;
- datos ficticios de demostración.

## No incluye

- datos de personas reales o preselecciones clínicas;
- alta disponibilidad productiva;
- identidad de marca definitiva;
- integraciones externas.
