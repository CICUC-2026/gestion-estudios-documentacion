# Definición de terminado

Una HU no está terminada por compilar o por tener un stub.

- [ ] HU, feature, issue y Project están sincronizados.
- [ ] Alcance, no-alcance y criterios de aceptación siguen vigentes.
- [ ] Permisos se validan en backend y tienen pruebas negativas.
- [ ] Contratos previos se preservan o existe migración/ADR aprobado.
- [ ] Migraciones son reproducibles cuando aplica.
- [ ] Tests unitarios, integración y E2E relevantes pasan.
- [ ] Build y lint pasan en los repositorios afectados.
- [ ] El flujo visible fue validado en navegador cuando aplica.
- [ ] No existen secretos ni datos reales en código, fixtures o logs.
- [ ] Auditoría y eliminación lógica se verificaron cuando aplica.
- [ ] Documentación y bitácora reflejan el comportamiento real.
- [ ] El trabajo fue revisado mediante pull request.
