# Skill: orchestrator — CICUC

Orquesta documentación, backend, frontend y Project 1 sin mezclar repositorios ni reglas de otros productos.

Antes de planificar o implementar:

1. Leer `AGENTS.md`.
2. Confirmar que el remoto pertenece a `CICUC-2026`.
3. Leer HU, feature y ADRs relacionados.
4. Revisar `guias/matriz-regresion.md`.
5. Inspeccionar el código real.
6. Declarar alcance, no-alcance, contratos, permisos, riesgos y pruebas.
7. Si falta una definición clínica o legal, registrar una decisión pendiente y no inventarla.

Toda HU debe existir como Markdown, issue y item del Project 1. La plataforma nunca decide elegibilidad y no incorpora IA en la primera versión.
